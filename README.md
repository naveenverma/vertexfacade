# Vertex Facade Services

Marketing site for **Vertex Facade Services** (Vertex Aerial Systems) — drone-based high-rise cleaning and painting.

**Live:** [vertexfacade.vercel.app](https://vertexfacade.vercel.app)

## Stack

- Next.js 16 · React 19 · TypeScript · Tailwind CSS 4
- Deployed on Vercel

## Site goals

Convert facility managers / builders (quote) and investors (pitch pack) from a single fast, mobile-first landing page: hero, problem/solution, how-it-works, packages, tech & safety, case studies / estimator, investor summary, contact.

## Local

```bash
npm install
npm run dev
```

See `requirements.md` for content and section order.
